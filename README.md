## 🚀 Featured Projects

### ⚖️ RoadLaw — Agentic RAG for Vietnamese Traffic Law

**[View Repository](https://github.com/bavuong2005/legal-agentic-rag)**

An intelligent legal question-answering assistant designed to help users understand Vietnamese traffic regulations through advanced retrieval and agentic reasoning.

**Key Features:**
- Hybrid Retrieval combining **BM25 + BGE Embeddings**.
- Cross-Encoder Reranking for improved retrieval relevance.
- LangGraph-based agentic workflow with conditional routing.
- Selective Reflection and Query Rewriting.
- Conversational memory and multi-turn question answering.
- Evaluation on Vietnamese legal questions, including ambiguous and noisy queries.

**Tech Stack:** Python, LangGraph, LangChain, BGE, Cross-Encoder, Weaviate, ChromaDB.

### 👕 Occlusion-Aware Virtual Try-On

**[View Repository](https://github.com/bavuong2005/occlusion-aware-viton)**

An enhanced virtual try-on pipeline built on StableVITON, designed to preserve occluding objects such as bags, arms, and hair during clothing generation.

**Key Features:**
- Grounding DINO for object detection.
- SAM for precise occlusion mask refinement.
- SegFormer for clothing segmentation.
- StableVITON for diffusion-based virtual try-on.
- Occlusion-aware post-processing to preserve foreground objects.

**Evaluation Results:**

| Metric | Baseline | Ours |
|:---|---:|---:|
| PSNR ↑ | 32.925 | **33.385** |
| LPIPS ↓ | 0.211 | **0.185** |
| FID ↓ | 152.830 | **105.558** |
| KID ↓ | 0.023 | **0.002** |

**Tech Stack:** Python, PyTorch, Stable Diffusion, Grounding DINO, SAM, SegFormer.
